Раздел 18 сохранён намеренно: Android-приложение исключено из объёма, и раздел фиксирует, какие работы снимаются и что не должно попадать в план как обязательное к запуску.

Чтобы добавить раздел, нужно положить новый `spec/NN-slug.json` и указать его в `file` соответствующей темы манифеста. Правки в `spec.html` не требуются. Разделы без `file` показываются в списке как «скоро».

Страница читает JSON через `fetch`, поэтому её нельзя открывать как локальный файл — только через сервер (см. ниже).

Поддерживаемые типы блоков внутри подтемы: `text`, `list`, `flow`, `states`, `defs`, `table`, `note` (`tone: design | open`). Статусы подтем задаются словарём `statuses` в манифесте — там же подпись к блоку решения (`decision`) и текст бейджа (`short`). Таблицы больше двух столбцов на узких экранах разворачиваются в список, где перед каждым значением подставляется заголовок столбца.

### Ответы на открытые вопросы

Каждый вопрос раздела — интерактивный: варианты ответа, «свой вариант», «затрудняюсь ответить» и поле комментария. Отправка своя у каждого раздела, не общая на все 30.

Схема ответа задаётся в вопросе полем `answer`:

```json
"answer": {
  "kind": "choice",                       // choice | text
  "options": [{ "t": "...", "rec": true }],   // для choice; rec — «рекомендуем»
  "aspects": ["..."],                          // что нужно охватить в ответе
  "placeholder": "...", "hint": "..."          // для text
}
```

Приёмник ответов настраивается одной константой `SUBMIT` в начале скрипта `spec.html`. Пока он не подключён, ответы сохраняются в браузере и доступна кнопка «Скопировать ответы». Инструкция и код скрипта для Google Таблицы — в [spec/ENDPOINT.md](spec/ENDPOINT.md).

Надёжность: автосохранение в `localStorage` на каждое изменение, очередь неотправленного с повторной отправкой при следующем открытии страницы, отдельный `submissionId` у каждой отправки, резервное копирование текста ответов.

## Публикация

Сайт публикуется через GitHub Pages из ветки `main` (корень репозитория).

Локальный просмотр:

```bash
python3 -m http.server 8000
```

Затем открыть http://localhost:8000

## Технические детали

Все документы — самодостаточные статические HTML-файлы: стили встроены, внешняя
зависимость одна — шрифты IBM Plex с Google Fonts. Сборка не требуется.

`durak.html` создан непосредственно в репозитории (оригинала на Рабочем столе нет, `sync.sh` его не трогает). Изображения в `img/durak/` — JPEG до 1920 px и миниатюры в `img/durak/t/`; папка `img/durak/raw/` хранит исходные PNG и не нужна для публикации.

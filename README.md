# Crypto Casino Platform — документы проекта

Комплект документов по проектированию и разработке криптовалютной игровой платформы под ключ.

## Состав

| Файл | Документ | Содержание |
| --- | --- | --- |
| `index.html` | Главная страница | Навигация по трём документам |
| `offer.html` | Коммерческое предложение | Состав поставки, стоимость, этапы, границы объёма, формат работы |
| `technical.html` | Технический документ | Архитектура, финансовое ядро, криптоинфраструктура, роли и доступы, интеграции |
| `questions.html` | Вопросы до начала работ | 14 решений заказчика перед стартом: варианты, последствия, рекомендации |

## Публикация

Сайт публикуется через GitHub Pages из ветки `main` (корень репозитория).

Локальный просмотр:

```bash
python3 -m http.server 8000
```

Затем открыть http://localhost:8000

## Технические детали

Все документы — самодостаточные статические HTML-файлы: стили встроены, внешняя
зависимость одна — шрифты IBM Plex с Google Fonts. Сборка не требуется.
